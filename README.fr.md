**L'agent IA autonome et auto-apprenant développé par [Workprise](https://workprise.com) et propulsé par les services [Claraprise](https://claraprise.com) / [Workprise.fr](https://workprise.fr).**

Clara est un agent IA conçu pour apprendre de ses expériences, créer des compétences de manière autonome, persister son contexte et exécuter des tâches complexes sur votre machine locale, VPS ou infrastructure cloud.

---

## Fonctionnalités Principales

- **Interface TUI & Web Dashboard complète** : Édition multiligne, autocomplétion des commandes, suivi d'exécution des outils en temps réel.
- **Intégrations Messageries 24/7** : Telegram, Discord, Slack, WhatsApp, Signal et CLI depuis un seul processus gateway.
- **Apprentissage continu & Mémoire persistante** : Création automatique de compétences personnalisées et recherche dans l'historique de session.
- **Planificateur Cron intégré** : Automatisation de rapports quotidiens, veilles et sauvegardes récurrentes en langage naturel.
- **Délégation et sous-agents** : Exécution de workflows parallèles avec sous-agents isolés.
- **Multi-modèles** : Compatible avec [Clara Portal](https://portal.claraprise.com), OpenAI, Anthropic, OpenRouter ou tout modèle local/serveur privé.

## Installation Rapide

### Linux, macOS, WSL2
```bash
curl -fsSL https://agent.claraprise.com/install.sh | bash
```

### Windows (PowerShell)
```powershell
iex (irm https://agent.claraprise.com/install.ps1)
```

---

## Démarrer avec Clara

```bash
# Lancer l'agent en mode interactif
clara

# Ouvrir le tableau de bord web
clara dashboard

# Lancer la passerelle multi-plateformes
clara gateway run
```
