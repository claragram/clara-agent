# @claraship/clara ☤

The self-improving AI agent CLI launcher by **[Claraship](https://claraship.com)**.

Run Clara anywhere directly from your terminal with `npx` or install globally with `npm`.

## Quick Start

```bash
# Run immediately without global installation
npx @claraship/clara

# Or install globally
npm install -g @claraship/clara
clara
```

## Features

- **Any Model:** Use Clara Portal, OpenRouter, OpenAI, Anthropic, or local endpoints.
- **Persistent Memory:** Autonomous knowledge curation across sessions.
- **Multi-Platform:** Terminal TUI, Telegram, Discord, Slack, WhatsApp, Signal.
- **Self-Improving:** Generates reusable procedural skills from completed tasks.
